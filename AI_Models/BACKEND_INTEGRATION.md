## 🔑 Important Notes

### Ordering
- **Input:** Files uploaded in order → index 0, 1, 2, ...
- **Output:** Results always reordered by index, so you can map back

### Resume IDs
- **Generated by Python:** UUID4 format
- **Store this:** Save `resume_id` for future reference
- **Use for:** Linking to candidates in your DB

### Status Handling
```csharp
foreach (var result in response.results)
{
    if (result.status == "success")
    {
        // Use extracted data: name, email, phone, linkedin, github
        // Store extracted_content if needed for search/analysis
    }
    else if (result.status == "failed")
    {
        // Log error: result.error
        // Handle gracefully (e.g., mark for manual review)
    }
}
```

## 🔄 Integration Workflow

### Candidate Upload Flow
```
1. User uploads resume files
   ↓
2. Backend collects files into byte array
   ↓
3. Backend calls POST /extract-resumes
   ↓
4. Python FastAPI processes in parallel
   ↓
5. Backend receives results with index preservation
   ↓
6. Backend stores extracted data in Candidates table
   ↓
7. Return success to Frontend
```

### Sample C# Controller Method

```csharp
[HttpPost("upload-resumes")]
[Authorize(Roles = AppRoles.Recruitment)]
public async Task<IActionResult> UploadResumes(
    [FromForm] List<IFormFile> files,
    [FromQuery] Guid jobId)
{
    try
    {
        var client = new HttpClient();
        var content = new MultipartFormDataContent();
        
        // Add files to multipart request
        for (int i = 0; i < files.Count; i++)
        {
            var bytes = new byte[files[i].Length];
            await files[i].OpenReadStream().ReadAsync(bytes, 0, bytes.Length);
            content.Add(
                new ByteArrayContent(bytes),
                "files",
                files[i].FileName
            );
        }
        
        // Call Python API
        var response = await client.PostAsync(
            "http://localhost:8000/extract-resumes",
            content
        );
        
        if (!response.IsSuccessStatusCode)
            return BadRequest("Extraction service failed");
        
        var jsonStr = await response.Content.ReadAsStringAsync();
        var batchResult = JsonSerializer.Deserialize<ResumeBatchResponse>(jsonStr);
        
        // Store successful results
        foreach (var result in batchResult.results.Where(r => r.status == "success"))
        {
            var candidate = new Candidate
            {
                Id = Guid.Parse(result.resume_id),
                Name = result.name,
                Email = result.email,
                Phone = result.phone,
                GitHub = result.github,
                LinkedIn = result.linkedin,
                JobId = jobId,
                Status = "under_review"
            };
            
            await _candidateService.CreateAsync(candidate);
        }
        
        return Ok(new { 
            total = batchResult.total,
            successful = batchResult.successful,
            failed = batchResult.failed
        });
    }
    catch (Exception ex)
    {
        logger.LogError($"Resume upload failed: {ex.Message}");
        return StatusCode(500, "Internal server error");
    }
}
```

## 📋 DTOs for C#

```csharp
public class ExtractedCandidate
{
    public int Index { get; set; }
    public string ResumeId { get; set; }
    public string Status { get; set; }
    public string Name { get; set; }
    public string Email { get; set; }
    public string Phone { get; set; }
    public string LinkedIn { get; set; }
    public string GitHub { get; set; }
    public string ExtractedContent { get; set; }
    public string Error { get; set; }
}

public class ResumeBatchResponse
{
    public int Total { get; set; }
    public int Successful { get; set; }
    public int Failed { get; set; }
    public List<ExtractedCandidate> Results { get; set; }
}
```

## 🔐 Error Handling

### Per-File Errors (Non-blocking)
```json
{
  "status": "failed",
  "error": "Unsupported file format: .txt"
}
```
→ Skip this file, continue with next

### API Errors (Blocking)
```csharp
if (!response.IsSuccessStatusCode)
{
    // Handle API unavailable, 500 errors, etc.
    // Could retry or fall back to manual processing
}
```

### Network Issues
- Implement retry logic (3-5 attempts)
- Log failures for manual review
- Don't crash the upload flow
